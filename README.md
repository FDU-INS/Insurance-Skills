## 项目简介

INS-Skill 是一个聚焦保险行业的 Agent Skill 平台，致力于为用户提供全面的保险场景 Skill 能力集合。  
我们希望通过统一的平台化方式，让用户能够在不同保险业务场景下，快速找到合适的 Skill，了解 Skill 的适用范围与质量水平，并完成高效集成与使用。

INS-Skill 不只是一个 Skill 清单，更是一个围绕 **“收集 - 评估 - 集成 - 使用”** 构建的一站式保险 Skill 平台。

---

## 我们想解决什么问题

在保险智能化和 Agent 应用落地过程中，用户通常会遇到以下问题：

### 1. 找不到合适的保险场景 Skill
保险业务链路长、场景细分多，不同环节对 Skill 的需求差异很大。  
用户往往缺少一个统一入口去查找真正适用于保险场景的 Skill。

### 2. 场景化 Skill 不知道怎么做
很多团队知道“要做保险 Agent”，但并不清楚具体场景下的 Skill 应该如何定义、拆分、设计与落地。  
缺少可参考、可复用、可对比的标准化能力。

### 3. 同样场景下的 Skill，不知道谁做得更好
即便面对同一个保险场景，也可能存在多个 Skill 方案。  
用户难以快速判断不同 Skill 在清晰度、完整度、可操作性、安全性等方面的差异。

### 4. 保险 Skill 不知道如何快速集成和使用
找到 Skill 只是第一步，更关键的是如何快速接入到业务系统、Agent 流程或实际应用场景中。  
用户需要更低门槛、更高效率的一站式集成体验。

INS-Skill 的核心目标是：

### 多维度测评

为了帮助用户更客观地理解 Skill 质量，INS-Skill 从以下五个维度对 Skill 进行测评与打分：

- **清晰度**：Skill 定义是否明确，适用场景是否清楚
- **完整度**：Skill 是否覆盖场景所需的核心能力
- **可操作性**：Skill 是否易于调用、接入和使用
- **可维护性**：Skill 是否具备持续迭代、更新和扩展能力
- **安全性**：Skill 在数据处理、调用流程和结果输出上是否具备安全保障

通过标准化测评机制，帮助用户快速判断：
- 某个 Skill 是否适合自己的业务场景
- 同类 Skill 中谁更优
- 哪些 Skill 更适合优先集成

## 平台能力概览

INS-Skill 当前围绕以下核心能力建设：

- **Skill 收集**：多渠道发现和汇聚保险场景 Skill
- **Skill 管理**：统一管理 Skill 的基础信息、适用场景和版本状态
- **Skill 检索**：支持按业务环节、场景类型、能力标签等方式快速检索
- **Skill 测评**：提供多维度评价与打分能力
- **Skill 集成**：支持 Skill 的快速接入与使用
- **持续更新**：跟踪保险场景变化与 Skill 演进情况
