# 보험 상품 상세 가이드

## 1. 생명보험

### 1.1 종신보험

**개요**: 피보험자 사망 시 보험금을 지급하는 보험. 보장 기간이 평생.

| 항목 | 내용 |
|------|------|
| 보장 기간 | 종신 (평생) |
| 보험료 | 높음 (정기 대비 5~10배) |
| 해약환급금 | 있음 (장기 유지 시 납입 보험료 대비 80~90%) |
| 주요 용도 | 상속 준비, 유족 생활 보장, 장례비 |

**장점**:
- 평생 보장으로 언제 사망해도 보험금 수령
- 해약환급금 적립 (비상자금 활용 가능)
- 보험료 납입 완료 후에도 보장 유지

**단점**:
- 높은 보험료 (같은 보장금액 대비 정기보험의 5~10배)
- 초기 해약환급금이 매우 낮음 (초기 해약 시 원금 손실)
- 보장보다 저축 기능에 현혹되기 쉬움

**적정 가입 시기**: 40대 이후, 소득이 충분하고 상속/유산 계획이 있는 경우

**주의사항**:
- 30대 이하는 정기보험이 더 효율적
- "종신보험 = 저축"이라는 설계사 권유에 주의
- 변액종신은 투자 리스크가 가산됨

### 1.2 정기보험

**개요**: 일정 기간(10년, 20년, 30년 등) 동안만 사망을 보장하는 보험.

| 항목 | 내용 |
|------|------|
| 보장 기간 | 10년/20년/30년 또는 특정 나이까지 |
| 보험료 | 낮음 (종신 대비 1/5~1/10) |
| 해약환급금 | 없음 또는 극소 |
| 주요 용도 | 가장 사망 시 가족 생활비, 대출 상환 |

**장점**:
- 매우 저렴한 보험료
- 높은 보장금액을 적은 비용으로 확보
- 단순한 구조로 이해하기 쉬움

**단점**:
- 만기 후 보장 소멸
- 해약환급금 없음 (순수 보장형)
- 갱신 시 보험료 대폭 인상

**적정 가입 시기**: 결혼, 출산 시점 (가족 부양 책임 발생 시)

**보장금액 산정 공식**:
```
필요 사망보장액 = (연간 생활비 x 필요 기간) + 부채 총액 + 자녀 교육비 - 기 보유 자산
예시: (3,600만원 x 20년) + 3억 + 1억 - 2억 = 9.2억
```

**추천 전략**:
- 비갱신형 선택 (보험료 고정)
- 대출 상환 기간에 맞춰 보장 기간 설정
- 자녀 독립 시점까지 보장 확보

### 1.3 변액보험

**개요**: 보험료의 일부를 펀드에 투자하여 운용 실적에 따라 보험금이 변동되는 보험.

| 항목 | 내용 |
|------|------|
| 유형 | 변액종신, 변액유니버셜, 변액연금 |
| 수수료 | 높음 (사업비 + 펀드 운용 보수) |
| 투자 리스크 | 있음 (원금 손실 가능) |
| 최저 보증 | 사망보험금 최저 보증 (일부 상품) |

**장점**:
- 투자 수익 기대 가능
- 인플레이션 대응
- 비과세 혜택 (10년 이상 유지, 요건 충족 시)

**단점**:
- 높은 사업비 (초기 7~10년간 사업비 비중 높음)
- 원금 손실 가능
- 복잡한 구조로 이해 어려움
- 동일 자금으로 보장 + 직접 투자가 더 효율적

**권장 대상**: 보장성 보험 충분히 확보한 고소득자, 10년 이상 장기 유지 가능한 경우

**비추천 대상**: 보장이 부족한 상태, 단기 해약 가능성 있는 경우, 투자 경험 없는 경우

### 1.4 저축성 보험 (연금보험, 저축보험)

**개요**: 보장 기능은 최소화하고 저축/연금 기능에 중점을 둔 보험.

| 유형 | 특징 | 세제 혜택 |
|------|------|----------|
| 일반 연금보험 | 비과세 (10년 이상, 월 150만원 이하 납입) | 이자소득 비과세 |
| 세제적격 연금저축보험 | 세액공제 | 납입액의 13.2~16.5% 세액공제 |
| 저축보험 | 만기환급금 | 비과세 요건 충족 시 이자소득 비과세 |

**주의사항**:
- 보장성 보험이 충분한 후에만 검토
- 초기 해약 시 원금 대비 큰 손실
- 사업비 차감 후 실질 수익률이 은행 예금보다 낮을 수 있음
- 비과세 혜택은 10년 이상 유지해야 적용

## 2. 손해보험

### 2.1 실손의료보험

**개요**: 실제 발생한 의료비를 보상하는 보험. 국민건강보험의 보완적 역할.

| 항목 | 내용 |
|------|------|
| 보장 범위 | 급여(본인부담금), 비급여(MRI, 초음파 등) |
| 자기부담금 | 급여 20%, 비급여 30% (4세대 기준) |
| 보험료 | 3~5만원/월 (나이, 세대에 따라 다름) |
| 갱신 주기 | 1년 (4세대), 3년 (3세대 이하) |

**세대별 차이**:

| 세대 | 자기부담 | 비급여 보장 | 특징 |
|------|---------|-----------|------|
| 1세대 (2009년 이전) | 10% | 전액 | 보장 최고, 보험료 급등 |
| 2세대 (2009~2017) | 10~20% | 전액 | 보장 양호 |
| 3세대 (2017~2021) | 20% | 일부 제한 | 비급여 특약 분리 |
| 4세대 (2021~) | 20~30% | 제한적 | 비급여 자기부담 확대 |

**핵심 조언**:
- **모든 가족 구성원 1인 1실손** 반드시 가입
- 기존 1~2세대 실손은 절대 해약하지 말 것 (재가입 불가)
- 4세대 전환은 보험료와 보장 비교 후 신중하게 결정
- 실손은 중복 가입해도 실손보상 원칙으로 중복 보상 불가

### 2.2 암보험

**개요**: 암 진단 시 진단금과 치료비를 보장하는 보험.

| 항목 | 내용 |
|------|------|
| 보장 범위 | 암 진단금, 수술비, 입원비, 항암치료비 |
| 유사암 | 갑상선암, 기타피부암, 제자리암, 경계성종양 |
| 적정 진단금 | 일반암 3,000~5,000만원 |
| 납입 기간 | 20년납 또는 30년납 비갱신형 권장 |

**가입 시 체크포인트**:
1. **일반암 진단금**: 최소 3,000만원 이상
2. **유사암 구분**: 유사암은 일반암의 10~20%만 지급하는 상품이 많음
3. **면책 기간**: 가입 후 90일간 면책 (이 기간 암 진단 시 보장 불가)
4. **감액 기간**: 가입 후 1~2년간 50% 감액 지급하는 상품 주의
5. **갱신 여부**: 비갱신형 선택 권장
6. **재진단암**: 재발/전이 시 재진단금 지급 여부 확인

**연령별 암 발생 통계 기반 전략**:
- 20~30대: 기본 진단금 + 유사암 보장
- 40대: 진단금 증액, 3대 암(위/간/폐) 추가 보장
- 50대 이상: 기존 보장 유지, 추가 가입 시 보험료 부담 고려

### 2.3 운전자보험

**개요**: 자동차사고 발생 시 형사적/행정적 책임 비용을 보장.

| 보장 항목 | 내용 | 권장 보장액 |
|-----------|------|-----------|
| 교통사고 처리지원금 | 형사합의금 | 3,000만원~1억 |
| 벌금 | 교통법규 위반 벌금 | 2,000만원 |
| 변호사 선임비 | 법률 비용 | 1,000~2,000만원 |
| 면허정지/취소 위로금 | 행정처분 시 | 일시금 |

**주의사항**:
- 자동차보험과 별도의 보험임 (자동차보험은 피해자 보상, 운전자보험은 가해자 본인 보장)
- 음주/무면허 운전 시 보장 제외
- 가족 중 운전자가 있으면 반드시 가입

### 2.4 화재보험

**개요**: 화재, 폭발 등으로 인한 건물/가재도구 피해 보장.

| 구분 | 내용 |
|------|------|
| 의무 가입 | 아파트 등 공동주택은 화재보험 의무 |
| 보장 범위 | 건물, 가재도구, 배상책임 |
| 특약 | 풍수해, 도난, 배상책임 |

**주택 소유자 필수 확인사항**:
- 공동주택 화재보험 의무가입 여부 확인
- 건물 가액 대비 적정 보장 (재조달가액 기준)
- 임차인 배상책임 특약 (전세/월세 세입자)

## 3. 제3보험

### 3.1 질병보험

**개요**: 특정 질병 진단/수술/입원 시 보험금을 지급.

| 주요 보장 | 내용 |
|-----------|------|
| 3대 질병 | 암, 뇌혈관질환, 심장질환 진단금 |
| 수술비 | 질병 수술 시 정액 보장 |
| 입원비 | 질병 입원 시 일당 |
| 통원비 | 질병 통원 시 정액 |

**3대 질병 보장 설계**:

| 질병 | 권장 진단금 | 보장 범위 주의 |
|------|-----------|--------------|
| 암 | 3,000~5,000만원 | 일반암 vs 유사암 구분 |
| 뇌혈관질환 | 3,000만원 이상 | "뇌출혈"만 보장 vs "뇌혈관질환" 전체 보장 구분 |
| 심장질환 | 3,000만원 이상 | "급성심근경색"만 vs "허혈성심장질환" 전체 구분 |

**핵심**: 보장 범위가 넓은 "뇌혈관질환", "허혈성심장질환" 기준 상품 선택

### 3.2 상해보험

**개요**: 급격하고 우연한 외래의 사고로 인한 신체 상해를 보장.

| 보장 항목 | 내용 |
|-----------|------|
| 상해 사망 | 사고 사망 시 보험금 |
| 상해 후유장해 | 사고로 인한 장해 등급별 보장 |
| 상해 수술비 | 사고로 인한 수술 시 정액 |
| 골절/화상 | 골절 진단비, 화상 진단비 |

### 3.3 간병보험 (장기요양보험)

**개요**: 치매, 뇌졸중 등으로 일상생활이 어려워진 경우 간병비를 보장.

| 항목 | 내용 |
|------|------|
| 보장 조건 | 장기요양등급 판정 (1~5등급) |
| 보장 금액 | 월 100~300만원 또는 일시금 |
| 가입 적기 | 40~50대 |

**고령화 시대 필수 보장**:
- 2025년 기준 65세 이상 치매 유병률 약 10%
- 간병비 월 200~400만원 소요
- 50대 이전 가입이 보험료 측면에서 유리

## 4. 보험료 적정 수준 가이드

### 소득 대비 보험료 비율

| 가구 소득 | 보장성 보험 | 저축성 보험 | 합계 | 비고 |
|-----------|-----------|-----------|------|------|
| 300만원 미만 | 15~20만원 | 0원 | 15~20만원 | 보장 최소화 |
| 300~500만원 | 20~35만원 | 0~15만원 | 20~50만원 | 핵심 보장 구축 |
| 500~700만원 | 35~50만원 | 0~20만원 | 35~70만원 | 보장 충실화 |
| 700~1,000만원 | 50~70만원 | 0~30만원 | 50~100만원 | 여유 보장 |
| 1,000만원 이상 | 70~100만원 | 상황별 | 70만원~ | 상속/절세 검토 |

### 연령대별 보험료 배분 가이드

| 연령 | 사망보장 | 의료/건강 | 연금/저축 | 기타 |
|------|---------|----------|----------|------|
| 20대 | 10% | 70% | 10% | 10% |
| 30대 | 30% | 50% | 10% | 10% |
| 40대 | 25% | 45% | 20% | 10% |
| 50대 | 15% | 40% | 35% | 10% |
| 60대~ | 5% | 50% | 35% | 10% |

### 보험료 과다 경고 신호

다음 중 하나라도 해당되면 보험료 재조정 필요:

1. 총 보험료가 가구 소득의 **12% 초과**
2. 저축성 보험료가 보장성 보험료보다 **높은** 경우
3. 갱신형 보험료가 매년 **10% 이상** 인상되는 경우
4. 보험료 납입 때문에 **비상자금**을 확보하지 못하는 경우
5. 보험료 납입으로 **대출 상환**에 지장이 있는 경우
