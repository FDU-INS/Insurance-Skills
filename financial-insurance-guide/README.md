# financial-insurance-guide

가족 재무 상담을 위한 보험 상품 분석 및 보장설계 가이드.

## 주요 기능

- 보험 상품 분석 및 비교
- 실손/종신/정기 보험 설계
- 암보험 및 질병 보장 분석
- 맞춤형 보장설계 제안
- 보험료 최적화 방법
- 보험 포트폴리오 리밸런싱

## 사용 방법

- 에이전트 전용 스킬 (자동 위임)
- 트리거: 보험, 실손, 종신, 정기, 암보험, 보장분석, 보험료, 보험 리밸런싱
