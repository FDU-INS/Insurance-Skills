# 보장분석 및 리밸런싱 가이드

## 1. 보장분석 프레임워크

### 1.1 보장분석이란

가족 구성원이 보유한 모든 보험의 보장 내역을 종합적으로 분석하여, 부족한 보장은 보완하고 과잉/중복 보장은 정리하는 과정입니다.

### 1.2 현재 보장 목록화

#### 보험 증권 정리 양식

각 보험 증권에서 다음 정보를 추출합니다:

```

```

### 1.3 필요 보장 산정

#### 사망 보장 필요액 계산

```
필요 사망보장액 = A + B + C - D

A = 유족 생활비 (월 생활비 x 12 x 필요 연수)
B = 부채 잔액 (주택담보대출 + 기타 대출)
C = 자녀 교육비 (자녀 수 x 대학까지 예상 비용)
D = 기 보유 금융자산 (예금 + 투자자산 + 퇴직금 예상)
```

**필요 연수 기준**:
| 가족 상황 | 필요 연수 |
|-----------|----------|
| 자녀 미취학 | 20~25년 |
| 자녀 초등학생 | 15~20년 |
| 자녀 중고등학생 | 10~15년 |
| 자녀 대학생/독립 | 5~10년 |
| 배우자만 (자녀 없음) | 10~15년 |

#### 의료/건강 보장 필요액

| 보장 항목 | 최소 권장 | 적정 권장 | 이유 |
|-----------|----------|----------|------|
| 암 진단금 | 3,000만원 | 5,000만원 | 치료비 + 소득 상실 보전 |
| 뇌혈관질환 진단금 | 3,000만원 | 5,000만원 | 장기 재활비용 |
| 심장질환 진단금 | 3,000만원 | 5,000만원 | 수술비 + 재활비용 |
| 수술비 (1회) | 100만원 | 300만원 | 실손 외 추가 비용 |
| 입원비 (1일) | 3만원 | 5만원 | 간병비 + 소득 보전 |

### 1.4 갭(Gap) 분석

#### 갭 유형별 대응

| 갭 유형 | 상태 | 대응 방안 |
|---------|------|----------|
| 보장 부족 | 필요액 > 현재 보장액 | 추가 가입 또는 기존 보장 증액 |
| 보장 과잉 | 현재 보장액 >> 필요액 | 감액 또는 일부 해약 |
| 보장 중복 | 동일 보장 2건 이상 | 불리한 조건 상품 정리 |
| 보장 공백 | 특정 항목 미가입 | 해당 보장 신규 가입 |
| 보장 만기 임박 | 곧 보장 종료 | 만기 전 대체 상품 확보 |

#### 갭 분석 우선순위 매트릭스

```
         발생 가능성 높음
              │
    ┌─────────┼─────────┐
    │ 2순위   │ 1순위   │
    │ 모니터링│ 즉시대응│
    │         │         │
────┼─────────┼─────────┼────
    │ 4순위   │ 3순위   │
    │ 관찰    │ 계획수립│
    │         │         │
    └─────────┼─────────┘
              │
         발생 가능성 낮음

  영향 작음 ────────── 영향 큼
```

- **1순위 (즉시 대응)**: 실손 미가입, 가장 사망보장 부족, 3대 질병 보장 없음
- **2순위 (모니터링)**: 갱신형 보험료 급등 예상, 만기 임박 보장
- **3순위 (계획 수립)**: 간병/요양 보장 미비, 자녀 보장 부족
- **4순위 (관찰)**: 소액 중복 보장, 부가 특약 과다

## 2. 보험 리밸런싱 가이드

### 2.1 리밸런싱이란

생애주기 변화에 맞춰 보험 포트폴리오를 재구성하는 과정입니다.

### 2.2 리밸런싱 트리거 이벤트

| 이벤트 | 조정 방향 | 구체적 액션 |
|--------|----------|------------|
| 결혼 | 사망보장 신규/증액 | 배우자 수익자 변경, 정기보험 가입 |
| 출산 | 사망보장 증액, 어린이보험 | 정기보험 보장금액 상향, 태아보험 |
| 주택 구입 | 사망보장 대출 연동 | 대출금 상당 정기보험 추가 |
| 소득 변화 | 보험료 비율 재점검 | 소득 대비 7~10% 유지 조정 |
| 자녀 독립 | 사망보장 감액 | 불필요한 교육비 보장 정리 |
| 은퇴 | 건강/간병 중심 전환 | 사망보장 최소화, 실손 유지 |
| 이혼 | 수익자 변경, 보장 재설계 | 보험 수익자 즉시 변경 |
| 부모 사망 | 상속 보험 검토 | 상속세 대비 필요 여부 확인 |

### 2.3 생애주기별 리밸런싱 전략

#### 20대 (사회초년생)

```
[목표] 최소 비용으로 기초 보장 확보
[월 보험료 목표] 10~20만원

필수 가입:
  ✓ 실손의료보험 (1건)
  ✓ 암보험 (진단금 2,000~3,000만원)
  ✓ 상해보험 (기본)

보류:
  × 종신보험 (아직 불필요)
  × 저축성 보험 (비상자금/투자 우선)
  × 연금보험 (연금저축펀드가 더 효율적)
```

#### 30대 (결혼/출산)

```
[목표] 가족 보장 체계 구축
[월 보험료 목표] 30~60만원 (부부 합산)

추가 가입:
  ✓ 정기보험 (가장: 연소득 x 5~10배)
  ✓ 배우자 암/건강보험
  ✓ 어린이보험 (출산 시)
  ✓ 운전자보험 (차량 보유 시)

증액 검토:
  ✓ 암보험 진단금 3,000~5,000만원으로 증액
  ✓ 뇌혈관/심장질환 보장 추가

점검:
  ✓ 대출 규모에 맞는 사망보장 확인
```

#### 40대 (자녀 성장기)

```
[목표] 건강 보장 강화, 은퇴 준비 시작
[월 보험료 목표] 50~80만원 (부부 합산)

강화:
  ✓ 3대 질병 보장 재점검 및 보완
  ✓ 간병보험 가입 검토 시작

점검:
  ✓ 갱신형 보험의 갱신 보험료 확인
  ✓ 보장 만기 시점 확인 및 대비
  ✓ 자녀 보험 보장 내역 점검

정리:
  ✓ 불필요한 특약 정리
  ✓ 저축성 보험 수익률 점검
```

#### 50대 (자녀 독립 준비)

```
[목표] 은퇴 대비 보장 재편, 불필요 보장 정리
[월 보험료 목표] 40~60만원 (부부 합산)

감액/정리:
  ✓ 자녀 독립에 따라 사망보장 감액
  ✓ 대출 상환에 따라 정기보험 감액
  ✓ 불필요한 특약 해지

강화:
  ✓ 간병보험 가입 (미가입 시)
  ✓ 실손의료보험 유지 확인

점검:
  ✓ 은퇴 후 보험료 납입 가능 여부
  ✓ 보장 만기와 은퇴 시점 정합성
```

#### 60대 이후 (은퇴)

```
[목표] 보험료 부담 최소화, 핵심 보장만 유지
[월 보험료 목표] 20~30만원 이하

유지:
  ✓ 실손의료보험 (절대 해약 금지)
  ✓ 암/3대질병 보장 (납입 완료된 것)
  ✓ 간병보험

정리:
  ✓ 사망보장 최소화 (장례비 수준)
  ✓ 갱신형 보험 중 보험료 과다 상품 정리
  ✓ 납입 완료되지 않은 저축성 보험 검토
```

## 3. 불필요한 보험 정리 기준

### 3.1 즉시 정리 대상

| 상황 | 이유 | 조치 |
|------|------|------|
| 동일 보장 3건 이상 중복 | 과잉 보장 | 조건 가장 나쁜 것 해약 |
| 보장 없는 순수 저축보험 (가입 2년 이내) | 수익률 불리 | 해약 후 다른 금융상품 |
| 갱신형 보험료가 비갱신형 전환 시 보험료보다 높아진 경우 | 비용 비효율 | 비갱신형으로 전환 |
| 사용하지 않는 특약 (일당, 통원 등) | 보험료 낭비 | 특약 해지 |

### 3.2 신중 검토 대상

| 상황 | 판단 기준 | 조언 |
|------|----------|------|
| 오래된 저축성 보험 (10년+) | 해약환급금 vs 유지 시 수익 비교 | 만기 임박 시 유지 권장 |
| 1~2세대 실손 | 보험료 부담 vs 보장 범위 | 가능한 유지 권장 |
| 납입 완료 보장성 보험 | 보장 필요성 확인 | 보장 필요하면 유지 |
| 비과세 요건 충족 임박 보험 | 잔여 기간 확인 | 요건 충족 후 판단 |

### 3.3 정리 순서

```
1. 중복 보장 중 조건 불리한 것 먼저 정리
2. 갱신형 중 보험료 급등 예상 상품 정리
3. 사용하지 않는 특약 해지
4. 보장 필요 소멸된 보험 정리
5. 저축성 보험 효율성 검토
```

**절대 정리하지 말 것**:
- 실손의료보험 (특히 1~2세대)
- 납입 완료된 암/3대질병 보험
- 유일한 사망보장 (부양가족이 있는 경우)

## 4. 보험금 청구 핵심 사항

### 4.1 보험금 청구 시효

| 유형 | 시효 | 기산점 |
|------|------|--------|
| 보험금 청구권 | **3년** | 보험 사고 발생일 |
| 보험료 반환 청구권 | 3년 | 해당 사유 발생일 |
| 해약환급금 청구권 | 3년 | 해약일 |

### 4.2 청구 시 필요 서류

| 보험금 유형 | 필요 서류 |
|------------|----------|
| 사망보험금 | 사망진단서, 사망자 주민등록등본, 수익자 신분증 |
| 진단금 | 진단서, 조직검사 결과지, 의무기록 사본 |
| 수술비 | 수술확인서, 진료비 영수증 |
| 입원비 | 입퇴원확인서, 진료비 영수증 |
| 실손의료비 | 진료비 영수증, 진료비 세부내역서, 처방전 |

### 4.3 보험금 청구 팁

1. **복수 보험 동시 청구**: 여러 보험사에 가입된 경우 모든 보험사에 동시 청구
2. **실손 + 정액 구분**: 실손은 실비 보상, 정액은 중복 수령 가능
3. **소멸시효 주의**: 3년 내 청구하지 않으면 소멸
4. **서류 보관**: 모든 진료 영수증과 서류는 최소 3년 보관
5. **보험사 분쟁 시**: 금융감독원 분쟁조정 제도 활용 (1332)

### 4.4 보험금 미청구 확인

- **내 보험 찾아줌** (금융감독원): 숨은 보험금 조회
- **보험다모아** (보험개발원): 가입 보험 통합 조회
- 매년 1회 이상 가입 보험 현황 점검 권장

## 5. 보험 vs 저축/투자 구분 원칙

### 5.1 기본 원칙

```
보험은 보장 수단 ≠ 재테크 수단

보장은 보험으로, 저축은 은행으로, 투자는 증권으로
```

### 5.2 저축성 보험 vs 직접 저축/투자 비교

| 항목 | 저축성 보험 | 은행 예금 | 펀드/ETF |
|------|-----------|----------|---------|
| 수익률 | 2~3% (사업비 차감 후) | 3~4% (정기예금) | 변동 (장기 5~8%) |
| 유동성 | 낮음 (해약 시 손실) | 높음 | 높음 |
| 원금 보장 | 만기 시 보장 | 보장 (5천만원) | 미보장 |
| 세제 혜택 | 비과세 (요건 충족 시) | 이자소득세 15.4% | 배당소득세 15.4% |
| 사업비 | 높음 (7~15%) | 없음 | 낮음 (0.1~1%) |

### 5.3 판단 기준

**보험으로 해결할 것**:
- 사망/질병/상해 위험 대비
- 감당 불가능한 경제적 손실 방지
- 보장 기능이 주목적인 경우

**보험 외 금융상품으로 해결할 것**:
- 자산 증식/저축 목적
- 노후 자금 마련 (연금저축펀드, IRP가 더 효율적)
- 단기~중기 목적자금 마련
- 비상자금 확보

### 5.4 저축성 보험 가입 전 체크리스트

```
□ 보장성 보험이 충분히 확보되었는가?
□ 비상자금 (생활비 6개월)이 확보되었는가?
□ 10년 이상 유지할 수 있는가?
□ 사업비 차감 후 실질 수익률을 계산했는가?
□ 같은 금액으로 다른 금융상품 대비 유리한가?
□ 비과세 요건을 충족할 수 있는가?
```

위 체크리스트에서 하나라도 "아니오"라면 저축성 보험 가입을 재고해야 합니다.
