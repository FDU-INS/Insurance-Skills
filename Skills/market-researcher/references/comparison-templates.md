# Comparison Templates

## Product Comparison Table

Use this structure when comparing products, services, or tools:

```markdown
## [Category]: Top [N] Picks for [User's Criteria]

### Quick Answer
[1-2 sentence recommendation for most users]

### Comparison Matrix

| Feature | Option A | Option B | Option C | Option D |
|---------|----------|----------|----------|----------|
| **Price** | $X | $X | $X | $X |
| **Key Spec 1** | value | value | value | value |
| **Key Spec 2** | value | value | value | value |
| **Key Spec 3** | value | value | value | value |
| **User Rating** | X/5 (N reviews) | X/5 (N reviews) | X/5 (N reviews) | X/5 (N reviews) |
| **Best For** | [use case] | [use case] | [use case] | [use case] |

### Detailed Breakdown

#### 1. [Winner] — Best Overall
- **Price**: $X
- **Why it wins**: [specific reasons with data]
- **Trade-offs**: [what you give up]
- **Best for**: [specific user profile]
- **Sources**: [URLs]

#### 2. [Runner-up] — Best Value
[Same structure]

#### 3. [Alternative] — Best for [Specific Need]
[Same structure]

### What to Avoid
- [Product/service to skip and why]

### Methodology
- Sources checked: [N]
- Data as of: [date]
- Criteria weighted: [list priority factors]
```

## Service Comparison (Credit Cards, Insurance, Subscriptions)

```markdown
## [Service Type]: Best Options for [User Profile]

### Quick Recommendation
[Direct answer for the user's specific situation]

### Cost Comparison

| | Option A | Option B | Option C |
|---|----------|----------|----------|
| **Monthly/Annual Cost** | $X | $X | $X |
| **Setup/One-time Fees** | $X | $X | $X |
| **Hidden Fees** | [list] | [list] | [list] |
| **Total Year-1 Cost** | $X | $X | $X |
| **Total Year-3 Cost** | $X | $X | $X |

### Benefits Comparison

| Benefit | Option A | Option B | Option C |
|---------|----------|----------|----------|
| **Primary benefit** | ✅ Detail | ✅ Detail | ❌ |
| **Secondary benefit** | ✅ Detail | ❌ | ✅ Detail |
| **Bonus feature** | ❌ | ✅ Detail | ✅ Detail |

### Fine Print
- [Important terms people miss]
- [Penalty clauses or rate changes]
- [Eligibility requirements]

### Verdict
- **If you prioritize X**: Choose [Option]
- **If you prioritize Y**: Choose [Option]  
- **If budget is tight**: Choose [Option]
```
